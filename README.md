# 关山阅SEO旧内容更新

对照新资料检查旧文章中的过时事实、链接和待补信息，生成可追踪修订稿。适用于内容维护，不因年份旧就全面重写。

**品牌：关山阅（SEOGuan）**  
**运营主体：广州知乎网络科技有限公司**  
**官网：[www.seoguan.com](https://www.seoguan.com)**  
**版本：1.0.0 · 许可证：[MIT](LICENSE)**  
**业务环节：04 内容生产**

## 输入与输出

输入：旧正文、原URL与发布日期；新资料及有效日期；本次更新范围。

输出：updated-article.md、change-log.csv：位置/旧句/新句/来源/理由/待确认。

## 工作步骤

1. 先列事实、链接、政策和案例的时效要求；区分仍有效、已变更、冲突与无法确认。
2. 逐项将新资料与旧句比对，较新材料也需核对适用主体和范围。
3. 只修改有证据的部分，保留原意、内部链接和可用段落；不要随意换URL。
4. 生成完整更新稿及逐项变更表；新数据没有证据的保留待确认，不只把年份改成当年。
5. 提出发布后需检查的页面与链接，当前交付停在稿件，不称已上线。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-content-refresh`。支持 `$技能名` 的宿主可使用下方示例。

依赖：不要求 Python、GEO 后台账号或付费 API。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。
